# 用这套风格做另一款产品

请使用本目录自己的 `preview/reference.mp4`、Remotion 源码和 `MOTION-SPEC.md` 作为具体风格依据，为下面的产品制作完整的 motion launch video。参考成片用于理解设计质量，源代码用于保留可控的运动结构。不要只读文字提示后另做一套通用的居中标题动画。

产品：[名称与官网]
核心流程：[用户带来什么 → 产品完成什么动作 → 用户得到什么可验证的结果]
品牌素材：[logo、主色、许可素材；缺失项用清楚标注的演示内容]

先选择产品自己的视觉逻辑。Trace 的“碎片资料 → 聚焦 → 有来源的答案”适合研究、知识库、搜索、分析类产品。新产品若是协作、生成或编辑工具，应换掉输入、界面动作和结果的表达；光学聚焦、空间接力、镜头特写等运动原则可以保留。不要只把 Trace 改成新名字。不要使用其他作者的原片或截图作为交付素材。

保留这套视觉语言：深色孔径与有层次的光场；大而轻的文字；文字与图像相互遮挡形成空间；代码绘制的产品界面特写；贯穿场景的选择框或品牌形状；明确的明暗、尺寸与运动速度对比。色彩随新产品调整，同时统一光晕、阴影、纸面、按钮和摄影调色。一个画面有一个主要视觉动作，不要每一场都排成标题、说明、卡片的网页。

运动的具体要求：

- 文字的大幅位移、字号收缩、字距收缩、逐字相位、焦点、透明度和退场分别控制。不要只靠淡入和小幅上移。
- 开头大字可从本片的约 740px 群组位移、0.69s 行程、33ms 字符间隔起步；短词约 240px / 0.47s。根据新文字的字形与长度重新布局，不要盲套数值。
- 入场曲线候选 `(0.13,1,0.325,1)`；相邻焦点间移动 `(0.64,0,0.16,1)`；离场加速 `(0.56,0,0.88,0.25)`。这些是本片实现参数，不是原作者披露的设置。检查位移量、曲线与时长共同形成的速度，不靠曲线名称判断质量。
- 高速横移时增加横向模糊；景深失焦另算；静止在焦点内的文字清晰。不要给所有元素永久套相同 blur。别把模糊层当成运动本身。
- 同一条路径上的词保持相对位置，焦点在它们之间移动。退场和入场衔接时，不能把两个词堆在中心交叉淡化。
- 用上一场已有的对象、运动方向或光线接住下一场：窗口扩大、输入框展开、引用打开原文。不要提前销毁还在运动的场景。
- 界面操作有因果：指针到达 → 按钮受压 → 结果响应。输入和结果必须有足够的阅读时间；需要加快时先压缩无信息的等待。
- 主体占幅、文字遮挡、前后景分层和局部裁切要在关键帧中成立。人物和界面不要都缩小放在大画布中央。
- 音乐从开头就建立节奏；旁白按语义分句对准产品动作。SFX 的峰值对准落点，转场声音可提前进入，稀疏使用点击声。不必让所有物体都对每一个鼓点机械跳动。

先检查入场、最大速度、清晰落定和场景交接四类帧，再检查整段运动。发现卡顿、突然换层、字被挡到无法辨认、指针没点中或声画错位，就在完整时间线上修正。最终交付完整 MP4 和可编辑源码，不能只交孤立精修片段。保留方便下一位制作者理解的关键帧、曲线、场景时间和音频标记。

素材先服从产品叙事，再统一配色。每张照片需要参与可见的工作场景、输入/结果，或由前后镜头建立的隐喻；不能只因为颜色好看就加入。本片用产品资料与证据框贯穿叙事，并以研究空间整理前后的摄影背景补充使用情境。保留光学质感、空间层次和构图方法，根据新产品重新选择具体内容。配色尽量来自物体和场景本身，保持自然肤色，不要依赖大幅旋转整张照片色相。

退场检查：不要把短距离漂移、停住和再次加速串成一个动作。开头三句使用 `flowExit`，群组在最后 340ms 内连续加速，位移继续到透明度归零之后；文字可见时，不能因为位移时间先结束而突然失去速度和运动模糊。阅读停留要明确，退场一旦开始就连贯完成。

本版本的连续物体线索：被选中的访谈文档 → 相同内容进入资料集合 → 同一句访谈成为答案的引用 → 引用的四角框收成品牌标识。迁移时保留这种能辨认的前后关系，不必保留“访谈”这个具体题材。

人物可以作为使用者保留：本版将橙色外套研究者放在资料的前后景之间，脸部和关键摘录有清楚的可视区域。人物不代替产品流程。摄影背景来自 ImageGen，用同一研究空间整理前/后的差异支持叙事；具体证据和 UI 仍由代码绘制。复用时，人物 RGB 文件必须与原透明遮罩一起保留。背景生成的文字只作远景纹理，不能当真实结论。
