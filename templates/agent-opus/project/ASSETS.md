# 素材来源

- `preview/reference.mp4`：2026-09-07 用户确认的 Agent Opus v19.10 演示成片的完整 720p 参考副本。源码导出为 1080p。本包不包含第三方设计参考影片。
- `public/agent-opus/`：Agent Opus 演示视频、派生截图与代理素材。它们是示例内容，换品牌应替换为该品牌的素材。
- `public/agent-opus/AO_Black.svg` 和配置中的 markPaths：Agent Opus 品牌图形；片尾字标和立体图形应同步替换。
- `public/audio/approved-master.m4a`：本项目生成、编辑后的批准混音，包含产品专属旁白。Lite 不包含独立分轨。
- `public/assets/`：Fraunces、Geist、Instrument Serif 字体，OFL 许可与字体一起保留。

本工程是可编辑模板与演示素材的交付，不授予示例品牌素材的通用转售权。公开新品牌视频时使用自己有权使用的素材。本包无账户连接、凭据或付费模型调用。
