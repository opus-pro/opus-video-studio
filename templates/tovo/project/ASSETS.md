# Assets

- `preview/reference.mp4`: 720p derivative of the user-approved TOVO final film, generated from this project's Remotion source. Viewing reference only; not an input to rendering.
- `public/audio/master.m4a`: AAC stream copied from the approved final film. Includes original API-generated music (`lyria-3-pro-preview`), English narration (`seed-audio-1.0`), and editorial accents derived from the music. Independent stems and service credentials are excluded.
- `public/grain.png`: procedural grain generated for the original project.
- `public/fonts/GeistVF.woff2`: Geist; accompanying SIL Open Font License in `Geist-OFL.txt`.
- `public/fonts/InstrumentSerif-Regular.ttf`: Instrument Serif; accompanying SIL Open Font License in `InstrumentSerif-OFL.txt`.
- Marks, charts, interface elements and icons are drawn in source. TOVO and the demonstration task are fictional.
