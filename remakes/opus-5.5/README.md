# Claude Opus 5.5 remakes

Every motion component in [`templates/`](../../templates/) remade blind by Claude Opus 5.5, next to the original.

The originals were built with GPT-6 in Codex and refined through several rounds of human review before they shipped. Claude Opus 5.5 then remade each one in Claude Code from its written spec alone, in a single pass with no human feedback. Judge for yourself: every pair below plays side by side, original on the left and remake on the right.

| | Original | Claude Opus 5.5 remake |
|---|---|---|
| Input | The spec, plus human review and revision | Only [`TASK.md`](pf-type-snap/project/TASK.md): the spec, the asset list and the project rules |
| Starting point | Its own project | An empty Remotion 4.0.484 project at the component's size, frame rate and length, with the same assets |
| Feedback | Human reviewers | None. The model rendered stills, reviewed them and iterated |
| Access to the other side | — | None: no original source, video demo or notes |

**27 precise specs** carry the original build notes, with exact timings, curves and geometry. **7 brief-only specs** had lost their notes, so the remake got only the one-paragraph catalogue description.

Median **15 minutes** and **5 self-review rounds** per remake (range 4–25 min, 526 min in total). One run per component; nothing was filtered or retried.

## Run a remake

```sh
npm run remakes:prepare -- <component-id>
cd remakes/opus-5.5/<component-id>/project
npm ci
npm run studio   # or: npm run render
```

Preparation restores the media from the original template's immutable release and verifies every file's SHA-256, so a remake never ships its own copy of an asset. Check the whole catalogue with `npm run remakes:check`.
